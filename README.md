# Sàn Học

Bảng giá thành tích và kỷ luật — mở trực tiếp trên Cốc Cốc / Chrome.

## Link web

Sau khi bật GitHub Pages, mở:

**https://kuze4mua-jpg.github.io/san-hoc/**

## Cách bật Pages (một lần)

1. Vào https://github.com/kuze4mua-jpg/san-hoc/settings/pages
2. **Source** → Deploy from a branch
3. Branch: **main** → folder **/ (root)** → Save
4. Đợi 1–2 phút rồi mở link trên.

## Dữ liệu

- Lưu trên trình duyệt (localStorage)
- **Xuất JSON** / **Nhập JSON** để mang sang máy khác
